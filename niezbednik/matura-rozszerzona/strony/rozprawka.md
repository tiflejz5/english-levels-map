# Rozprawka

## Dwa popularne typy

- **Opinion essay.** Masz stanowisko i bronisz go.
- **For and against.** Pokazujesz zalety i wady, potem własny wniosek.

## Struktura

1. **Wstęp:** temat, krótko, bez opinii (w for and against) lub z tezą (w opinion essay).
2. **Rozwinięcie 1:** pierwszy element z przykładem.
3. **Rozwinięcie 2:** drugi element z przykładem.
4. **Zakończenie:** podsumowanie i opinia.

## Zwroty

| Funkcja | Zwroty |
| --- | --- |
| Wstęp | Nowadays..., It is often said that..., There is a growing debate about... |
| Dodawanie | Furthermore, In addition, Moreover |
| Kontrast | However, On the other hand, Nevertheless |
| Przyczyna | Because of, Due to, As a result |
| Przykład | For instance, A good example is |
| Opinia | In my opinion, I strongly believe that, It seems to me that |
| Zakończenie | To sum up, All things considered, In conclusion |

## Błędy do uniknięcia

- Brak przykładu przy argumencie.
- Zbyt długi wstęp.
- Skróty i slang.
- Brak zakończenia.
