# Wypowiedź pisemna

Jeden tekst za **13 punktów**, **200–250 wyrazów**. Wybierasz jeden z dwóch tematów. Forma: rozprawka, list formalny lub artykuł.

## Punktacja (orientacyjnie wg opracowań CKE)

| Kryterium | Punkty |
| --- | --- |
| Realizacja zadania (treść i forma) | 0–5 |
| Spójność i logika | 0–2 |
| Zakres środków językowych | 0–3 |
| Poprawność środków językowych | 0–3 |

- Poniżej **160 wyrazów** ocenia się tylko realizację zadania.
- 0 za realizację zadania oznacza 0 za całość.
- Na poziomie rozszerzonym liczą się też błędy w interpunkcji i pisowni.

## Czego wymaga treść

1. Wstęp.
2. **Dwa elementy tematu** (np. zalety i wady, dwie propozycje).
3. Zakończenie (podsumowanie, własna opinia lub prośba).
4. Cechy formy: styl, układ, akapity.

## Plan 220 wyrazów

| Część | Wyrazy |
| --- | --- |
| Wstęp | 30–40 |
| Element 1 | 70–80 |
| Element 2 | 70–80 |
| Zakończenie | 30–40 |

## Rejestr

Formalny: bez skrótów (don't, it's), bez slangu, z łącznikami: furthermore, nevertheless, in contrast, as a result.
