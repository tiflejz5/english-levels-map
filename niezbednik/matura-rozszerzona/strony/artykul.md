# Artykuł

## Cechy

- **Tytuł** przyciągający uwagę.
- **Pierwsze zdanie**, które zaciekawia: pytanie, fakt, krótka scena.
- Styl półformalny, przyjazny, dla czytelnika magazynu.
- Opinie autora są dozwolone.

## Struktura

1. Tytuł.
2. Wstęp z haczykiem.
3. Dwa akapity rozwinięcia, każdy z przykładem.
4. Zakończenie z opinią lub zachętą.

## Zwroty

- Have you ever wondered...?
- Imagine...
- One of the main reasons is...
- What is more, ...
- All in all, ...
- If you ask me, ...

## Błędy do uniknięcia

- Brak tytułu.
- Zbyt formalny ton jak w liście.
- Zbyt krótki tekst: poniżej 160 wyrazów oceniana jest tylko realizacja zadania.
