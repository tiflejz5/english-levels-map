# Implikacje, podteksty, humor i aluzje

Native speakerzy – zwłaszcza Brytyjczycy – często nie mówią wprost tego, co myślą. Na C1 rozumiesz nie tylko słowa, ale też **intencję**: uprzejmą odmowę ukrytą w komplemencie, krytykę w formie pytania czy aluzję do znanego filmu.

## Co mówią, a co mają na myśli

| Co słyszysz | Co to zwykle znaczy |
| --- | --- |
| *That's an interesting idea.* | Nie podoba mi się to. |
| *With all due respect…* | Zaraz się z tobą mocno nie zgodzę. |
| *I'll bear it in mind.* | Raczej nic z tym nie zrobię. |
| *I hear what you're saying.* | Nie zgadzam się i nie zmienię zdania. |
| *Not bad.* | Całkiem dobrze, a nawet bardzo dobrze. |
| *Quite good.* (BrE) | Takie sobie. |
| *Could we consider other options?* | Ta opcja mi nie odpowiada. |
| *I was a bit disappointed that…* | Jestem bardzo niezadowolony. |
| *We should get together sometime!* | Miło było, ale konkretnych planów nie ma. |
| *Correct me if I'm wrong, but…* | Wiem, że mam rację. |
| *Perhaps you could think about…* | Zrób to. |
| *No worries if not!* | Naprawdę by mi zależało. |

## Humor – typowe rodzaje

| Rodzaj | Przykład |
| --- | --- |
| Niedopowiedzenie (understatement) | Po wielkiej burzy: *Bit of a breeze last night.* |
| Autoironia (self-deprecation) | *I'm not saying I'm a bad cook, but the smoke alarm cheers me on.* |
| Gra słów (pun) | *I used to be a banker, but I lost interest.* |
| Deadpan – poważna mina przy żarcie | *Oh yes, I love spending Sundays doing my taxes.* |

## Aluzje kulturowe

| Aluzja | Znaczenie |
| --- | --- |
| *a Catch-22 situation* | sytuacja bez wyjścia (z powieści Josepha Hellera) |
| *Big Brother is watching* | inwigilacja (z „Roku 1984” Orwella) |
| *his Achilles' heel* | czuły punkt |
| *a Trojan horse* | coś podstępnie wprowadzonego |
| *opening Pandora's box* | wywołanie lawiny problemów |
| *a David and Goliath battle* | starcie słabego z silnym |
| *the elephant in the room* | oczywisty problem, o którym nikt nie mówi |

## Typowe błędy Polaków

- ❌ branie *That's interesting* jako aprobaty – sprawdź ton i kontekst.
- ❌ odpowiadanie na *We should get together sometime!* propozycją konkretnej daty, gdy to tylko uprzejmość (choć czasem to dobra okazja!).
- ❌ dosłowne rozumienie *Not bad* jako „słabo”.
- ❌ odpowiadanie śmiertelnie poważnie na żart rzucony z kamienną twarzą.

## Ćwiczenie

Co naprawdę znaczy ta wypowiedź?

1. Szef po Twojej propozycji: *Hmm, that's an interesting approach.*
2. Brytyjski kolega o Twojej prezentacji: *Not bad at all!*
3. Klient: *I'll bear that in mind.*
4. Współpracownik: *With all due respect, I think we need more data.*
5. Znajomy po burzy, która zerwała dach: *Bit windy yesterday, wasn't it?*

## Odpowiedzi

1. Raczej mu się nie podoba – warto dopytać lub przygotować alternatywę.
2. Szczery komplement – było naprawdę dobrze.
3. Prawdopodobnie nie skorzysta z sugestii.
4. Zdecydowanie się nie zgadza.
5. Niedopowiedzenie (understatement) – burza była potężna.
