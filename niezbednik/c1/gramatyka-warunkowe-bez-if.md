# Okresy warunkowe bez if

W formalnym angielskim *if* często znika, a jego miejsce zajmuje **inwersja**. Spotkasz to w e-mailach biznesowych, umowach, przemówieniach i literaturze. Do tego dochodzi kilka słów, które zastępują *if* i doprecyzowują warunek.

## Inwersja zamiast if

| Z if | Bez if (inwersja) | Typ |
| --- | --- | --- |
| If I had known… | ***Had I known**, I would have helped.* | Third Conditional |
| If you should need anything… | ***Should you need** anything, please contact me.* | First (formalne) |
| If I were in your position… | ***Were I** in your position, I would accept.* | Second |
| If it weren't for your help… | ***Were it not for** your help, we would fail.* | Second |
| If it hadn't been for the rain… | ***Had it not been for** the rain, we would have won.* | Third |
| If they were to refuse… | ***Were they to** refuse, we would have to reconsider.* | Second (hipotetycznie) |

**Przeczenie:** *not* stoi po podmiocie, bez skrótu: ✅ ***Had I not** seen it…* ❌ *Hadn't I seen it…*

## Alternatywy dla if

| Wyrażenie | Znaczenie | Przykład |
| --- | --- | --- |
| provided / providing (that) | pod warunkiem że | *You can borrow it, **provided** you return it tomorrow.* |
| as long as / so long as | o ile, pod warunkiem że | ***As long as** you're happy, I'm happy.* |
| on condition that | pod warunkiem że (formalnie) | *They agreed **on condition that** the price stayed the same.* |
| unless | chyba że, jeśli nie | *I won't go **unless** you come too.* |
| supposing / suppose | załóżmy, że | ***Supposing** you won the lottery, what would you do?* |
| otherwise | w przeciwnym razie | *Hurry up, **otherwise** we'll miss it.* |
| but for + rzeczownik | gdyby nie | ***But for** her support, I would have given up.* |
| in case | na wypadek gdyby | *Take an umbrella **in case** it rains.* |

## Przykłady

| Angielski | Polski |
| --- | --- |
| Should you have any questions, don't hesitate to contact us. | W razie pytań prosimy o kontakt. |
| Had we left earlier, we wouldn't have missed the flight. | Gdybyśmy wyszli wcześniej, zdążylibyśmy na samolot. |
| Were it not for the cost, I'd buy it tomorrow. | Gdyby nie cena, kupiłbym to od razu. |
| Had it not been for the doctor, he would have died. | Gdyby nie lekarz, zmarłby. |
| I'll lend you the car, provided you drive carefully. | Pożyczę ci samochód, pod warunkiem że będziesz jechał ostrożnie. |

## Typowe błędy Polaków

- ❌ *Hadn't I known…* → ✅ *Had I not known…*
- ❌ *Should you will need…* → ✅ *Should you need…*
- ❌ *Were it not the weather…* → ✅ *Were it not **for** the weather…*
- ❌ *in case* jako *if*: *In case you win, call me.* → ✅ *If you win, call me.*

## Ćwiczenie

Przekształć zdania bez użycia *if*.

1. If I had known about the problem, I would have fixed it.
2. If you need any help, please let me know.
3. If it weren't for my sister, I'd be lost.
4. If I were you, I'd take the job.
5. If it hadn't been for the traffic, we'd have arrived on time.
6. If the company were to close, hundreds would lose their jobs.
