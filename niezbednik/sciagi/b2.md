# Ściąga B2

## Czasy i formy

| Forma | Budowa | Przykład |
| --- | --- | --- |
| Future Continuous | will be + -ing | *Don't call at 8 – I'll be having dinner.* |
| Future Perfect | will have + 3. forma | *By next year, I'll have saved enough for a car.* |
| Past Perfect Continuous | had been + -ing | *She had been working there for ten years before she got promoted.* |
| Modalne w przeszłości | modal + have + 3. forma | *It must have rained. We should have booked.* |
| Third / mixed conditional | If + had + 3. forma, would have + 3. forma | *If we'd booked earlier, it would have been cheaper.* |
| wish / if only | wish + Past (teraz); had + 3. forma (przeszłość) | *I wish I lived closer. I wish I hadn't said that.* |
| have something done | have + rzecz + 3. forma | *I had my hair cut.* |
| Mowa zależna (czasowniki) | denied / admitted + -ing; offered + to | *He denied breaking it. She offered to help.* |

## Gramatyka

- **Gerund / infinitive:** *stop doing* (przestać) – *stop to do* (zatrzymać się, żeby); *remember to lock* (pamiętać o) – *remember saying* (pamiętać, że). [[b2-gramatyka-gerund-infinitive-zmiana-znaczenia]]
- **Przeciwieństwo i przyczyna:** *despite / in spite of* + rzeczownik lub -ing (bez *of*!); *although* + zdanie (bez *but*); *whereas*; *because **of*** + rzeczownik.
- **Zdania względne:** definiujące bez przecinków (*that* możliwe); niedefiniujące z przecinkami i tylko *who / which*: *…, which was a surprise.*
- **by / until:** *by Friday* = najpóźniej do piątku; *until Friday* = aż do piątku.
- **Czasowniki stanu** bez -ing: *I'll have **known** her for ten years.*
- **Przypuszczenia o przeszłości:** *must have been*, *can't have seen* – nie: *mustn't have*.
- **Po by the time / when** czas teraźniejszy: *By the time you arrive …*
- **Pytania w mowie zależnej** mają szyk zdania: *He asked me where I worked.*

## Słowa-sygnały

| Słowo | Czas / struktura |
| --- | --- |
| by next year, by Friday, by the time | Future Perfect |
| at 8 tomorrow (w trakcie) | Future Continuous |
| … for ten years before, How long had …? | Past Perfect Continuous |
| wish, if only | Past / Past Perfect |
| although, whereas, even though | + zdanie |
| despite, in spite of, because of | + rzeczownik / -ing |

## Uwaga na

- ✗ I'll finish it until Friday. → ✓ **I'll have finished it by Friday.**
- ✗ If I would have known, I would have come. → ✓ **If I had known, I would have come.**
- ✗ I wish I didn't say that. → ✓ **I wish I hadn't said that.**
- ✗ Despite of the rain … → ✓ **Despite the rain …**
- ✗ He must be tired yesterday. → ✓ **He must have been tired yesterday.**
