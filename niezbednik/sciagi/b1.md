# Ściąga B1

## Czasy i formy

| Forma | Budowa | Przykład |
| --- | --- | --- |
| Past Perfect | had + 3. forma | *By the time we arrived, the train had left.* |
| Present Perfect Continuous | have/has been + -ing | *I've been waiting for an hour.* |
| used to | used to + bezokol.; didn't use to; Did … use to? | *I used to play football.* |
| will / going to / Present Continuous | decyzja teraz / plan / ustalone | *I'll get it.* *I'm going to renovate.* *I'm having dinner on Friday.* |
| Strona bierna | be + 3. forma | *Cars are made here.* *The flight has been cancelled.* |
| Warunki 0 / 1 / 2 | If + Present, Present / will / If + Past, would | *If it rains, we'll stay.* *If I won, I would quit.* |
| Mowa zależna | czas „cofamy”; say / tell + osoba | *He said he was busy.* *She told me she had lost her job.* |

## Gramatyka

- **Przypuszczenia:** *must be* (na pewno), *might / may be* (może), *can't be* (to niemożliwe) – nie: *mustn't be*. [[b1-gramatyka-modalne-przypuszczenia]]
- **Pytania pośrednie:** szyk zdania, nie pytania – *Could you tell me where the station **is**?* Bez pytajnika: *if* / *whether*.
- **Zdania względne:** *who* (osoby), *which* (rzeczy), *that* (oba), *where* (miejsca); bez powtórzenia *it*: *The book that I read was good.*
- **too / enough, so / such:** *too tired to go*, *old **enough***, *so nice*, *such a nice day*.
- **Strona bierna:** *by* tylko gdy wykonawca jest ważny: *written by Shakespeare*. *Happen, arrive, die* nie mają strony biernej.
- **Mowa zależna:** *tell* + osoba (*told me to close the door*); *say* bez osoby.
- **W warunku 1 po if nigdy will:** *If it rains…*; *unless* = *if … not*, więc bez *don't*.
- **Advice** jest niepoliczalne: *some advice*, *a piece of advice*.

## Słowa-sygnały

| --- | --- |
| for, since, ever, never, just, already, yet, so far | Present Perfect |
| How long …? (trwa do teraz), all day, recently | Present Perfect Continuous |
| ago, yesterday, in 2019, When …? | Past Simple |
| before, after, by the time | Past Perfect |
| unless | if … not |

## Uwaga na

- ✗ I live here for 3 years. → ✓ **I've lived here for 3 years.**
- ✗ If it will rain, we'll stay. → ✓ **If it rains, we'll stay.**
- ✗ He said me that … → ✓ **He told me that …**
- ✗ Could you tell me where is the station? → ✓ **… where the station is?**
- ✗ He isn't enough old. → ✓ **He isn't old enough.**
