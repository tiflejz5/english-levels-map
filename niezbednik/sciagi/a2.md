# Ściąga A2

## Czasy i formy

| Forma | Budowa | Przykład |
| --- | --- | --- |
| Past Simple | 2. forma / did + bezokol. | *We went to Zakopane.* *Did you go?* |
| Past Continuous | was/were + -ing | *I was cooking when you called.* |
| Present Perfect | have/has + 3. forma | *Have you ever been to Rome?* |
| will | will + bezokol. | *I think it will rain.* |
| Present Continuous (plany) | am/is/are + -ing | *I'm meeting Ola on Friday.* |
| going to | am/is/are going to + bezokol. | *I'm going to learn Spanish.* |

## Gramatyka

- **Stopniowanie:** cheap → cheaper → the cheapest; expensive → more → the most; good → better → the best. [[a2-gramatyka-stopniowanie-przymiotnikow]]
- **Częstotliwość przed czasownikiem:** *I **often** walk.* Ale po *be*: *She is **always** late.*
- **Policzalne:** many, a few, How many? · **Niepoliczalne:** much, a little, How much? · a lot of – oba.
- **must / have to / should:** must – sam uważam, że trzeba; have to – zasada z zewnątrz; should – rada. **mustn't** = nie wolno, **don't have to** = nie musisz.
- **Pytanie o podmiot bez do/did:** *Who called you?* (nie: Who did call you?)
- **Czasownik + -ing / to:** enjoy, finish, mind + **-ing**; want, decide, hope + **to**.

## Słowa-sygnały

| Słowo | Czas |
| --- | --- |
| yesterday, last week, ago, in 2020 | Past Simple |
| when, while (tło) | Past Continuous + Past Simple |
| ever, never, already, yet, just | Present Perfect |
| I think, probably, maybe | will |
| tonight, on Friday (ustalone) | Present Continuous |

## Uwaga na

- ✗ I have been in Paris last year. → ✓ **I went to Paris last year.** (konkretny czas = Past Simple)
- ✗ Did you went? → ✓ **Did you go?**
- ✗ You mustn't come. (gdy chodzi o „nie musisz”) → ✓ **You don't have to come.**
- ✗ I must to go. → ✓ **I must go.**
- ✗ I'm enjoy to swim. → ✓ **I enjoy swimming.**
