# Ściąga C2

## Struktury

| Struktura | Budowa | Przykład |
| --- | --- | --- |
| Fronting z *as* | Strange as it may seem, … / Much as I'd like to, … | *Much as I'd like to, I can't.* |
| Inwersja z *so* | So + przymiotnik + was / were + podmiot + that | *So great was the demand that …* |
| Here / there | z zaimkiem bez inwersji | *Here he comes.* (nie: *Here comes he.*) |
| Subjunctive | że + forma podstawowa (bez -s, bez to); BrE także should | *I suggest that he go.* (BrE: *that he should go*) |
| Stałe wyrażenia | if need be; be that as it may | *We'll work through the night if need be.* |

## Gramatyka

- **Fronting:** *Much as I'd like **to**, …* (nie: *Much as I would like, …*); *Strange as it may seem, …*
- **Subjunctive:** *demand / suggest / recommend that he **pay*** (nie: *pays*); BrE też *that he **should** pay / shouldn't come*. [[c2-gramatyka-subjunctive]]
- **Rejestr:** *shall* w umowie to obowiązek, nie przyszłość; *I hereby inform you …* → w mailu *I'm writing to let you know …*
- **Slang:** *gonna, wanna, ain't* nie pasują do e-maila służbowego.
- **Słabe formy:** *I can /kən/ swim*, nie *can /kæn/* – pełna forma brzmi sztywno.
- **Akcent wyrazowy:** *deVElop*, *COMfortable* (trzy sylaby), *phoTOgraphy*.
- **Intonacja:** płaska brzmi jak znudzenie lub niegrzeczność.
- **Understatement:** *That's a bit of a problem* może oznaczać katastrofę.

## Słowa-sygnały

| Słowo | Struktura |
| --- | --- |
| Strange as it may seem, Much as I'd like to | fronting z *as* |
| So great was … that | inwersja z *so* |
| suggest, demand, recommend, essential, vital + that | subjunctive |
| shall (w umowie), hereby | rejestr prawniczy |

## Uwaga na

- ✗ So great the demand was that … → ✓ **So great was the demand that …**
- ✗ Here comes he. → ✓ **Here he comes.**
- ✗ I suggest him to go. → ✓ **I suggest that he go.**
- ✗ They demanded that he pays. → ✓ **They demanded that he pay.**
- ✗ Much as I would like, … → ✓ **Much as I'd like to, …**
