# Słownictwo tematyczne

Podstawa programowa dzieli słownictwo na tematy. Poniżej każdy temat i przykładowe słowa. To lista startowa, nie komplet.

| Temat | Przykładowe słowa |
| --- | --- |
| Człowiek | name, age, birthday, tall, friendly, funny |
| Dom | flat, house, kitchen, bedroom, garden, furniture |
| Szkoła | lesson, teacher, subject, homework, exam, break |
| Praca | job, doctor, driver, teacher, office, salary |
| Życie rodzinne i towarzyskie | parents, brother, cousin, friend, party, neighbour |
| Żywienie | breakfast, lunch, dinner, vegetables, fruit, delicious |
| Zakupy i usługi | shop, price, cheap, expensive, receipt, customer |
| Podróżowanie i turystyka | ticket, airport, hotel, luggage, holiday, passport |
| Kultura | film, concert, museum, painting, book, theatre |
| Sport | football, swimming, match, team, win, lose |
| Zdrowie | headache, doctor, medicine, ill, healthy, ambulance |
| Nauka i technika | computer, internet, phone, app, password, download |
| Świat przyrody | weather, rain, snow, forest, animal, river |
| Państwo i społeczeństwo | country, city, flag, police, capital, language |

## Jak się uczyć

1. Jeden temat tygodniowo, 15 słów.
2. Każde słowo w zdaniu, nie samo.
3. Słowa z dziennika błędów dopisuj na bieżąco.
