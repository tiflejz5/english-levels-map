# Znajomość funkcji językowych

Zadania sprawdzają, czy wiesz, **co powiedzieć** w danej sytuacji: poprosić, przeprosić, zaproponować, zgodzić się, odmówić.

## Jak rozwiązywać

1. Przeczytaj całą sytuację, nie tylko ostatnie zdanie.
2. Ustal funkcję: propozycja? prośba? przeprosiny? podziękowanie?
3. Odrzuć odpowiedzi, które brzmią poprawnie, ale nie pasują do funkcji.

## Najważniejsze funkcje i zwroty

| Funkcja | Zwroty | Reakcja |
| --- | --- | --- |
| Propozycja | Shall we...? Why don't we...? How about...? | Good idea. / Sorry, I can't. |
| Prośba | Could you...? Can you...? Would you mind...? | Sure. / Of course. / Sorry, I can't. |
| Przeprosiny | I'm sorry. / Sorry I'm late. | That's OK. / No problem. |
| Podziękowanie | Thanks. / Thank you very much. | You're welcome. / No problem. |
| Zaproszenie | Would you like to come to...? | I'd love to. / I'm afraid I can't. |
| Rada | You should... / Why don't you...? | Good idea. / Thanks for the advice. |
| Pytanie o drogę | How can I get to...? Excuse me, where is...? | Go straight. Turn left. |
| W sklepie / restauracji | Can I have...? / How much is it? | Here you are. |

## Pułapki

- **Fałszywi przyjaciele:** Excuse me (zwrócenie uwagi) i Sorry (przeprosiny) to nie to samo.
- **Odpowiedź trafna, ale z innej sytuacji:** na „Would you like some tea?” pasuje „Yes, please”, nie „Yes, I'd like”.
- **Za dużo:** poprawna reakcja bywa krótka. Nie szukaj bardziej skomplikowanej.
