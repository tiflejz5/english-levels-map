# Gramatyka pod egzamin

Ta strona zbiera struktury, które najczęściej wracają w **Part 4 (transformacje)**, ale przydają się też w Part 2, w Writing i w Speaking. Przy każdej masz link do podstrony z pełnym wyjaśnieniem i do zestawu ćwiczeń w formacie egzaminu.

## Jak czytać polecenie w Part 4

1. **Porównaj zdania** i nazwij zmianę: czynna → bierna? czasownik → rzeczownik? brak *if* → *if*?
2. **Słowo kluczowe podpowiada strukturę:**

| Słowo kluczowe | Najczęstsza struktura |
| --- | --- |
| SPITE, DESPITE | *in spite of / despite + rzeczownik lub -ing* (*a lack of*) |
| ALLEGED, SAID, BELIEVED, THOUGHT | *is alleged / said… to (have)…* |
| BEEN | *If it hadn't been for…*, strona bierna perfect, *has been -ing* |
| NEARLY, NOWHERE, FAR | *not nearly as… as*, *nowhere near as… as*, *far more…* |
| HAD, SOONER, ONLY, NEVER | inwersja, Past Perfect |
| WISH, ONLY (If only) | *wish + Past Simple / Past Perfect* |
| DIFFERENCE, LIGHT, TAKES | stałe zwroty: *makes no difference to*, *in the light of*, *whatever it takes* |
| COMPARISON, EXPLANATION, LACK | nominalizacja: *in comparison with*, *give an explanation of*, *a lack of* |

3. **Sprawdź na koniec:** 3–6 słów, słowo kluczowe bez zmian, ten sam czas i to samo znaczenie.
