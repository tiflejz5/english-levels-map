# Słownictwo tematyczne

Podstawa programowa obejmuje te obszary. To lista startowa.

| Temat | Przykładowe słowa i zwroty |
| --- | --- |
| Człowiek | appearance, personality, relationship, generous, shy |
| Dom | tenant, rent, neighbourhood, furniture, move house |
| Szkoła | exam, grade, timetable, revise, cheat, scholarship |
| Praca | employer, salary, apply for a job, part-time, experience |
| Życie rodzinne i towarzyskie | get on with, argue, celebrate, generation gap |
| Żywienie | vegetarian, recipe, ingredients, fast food, balanced diet |
| Zakupy i usługi | refund, discount, receipt, bargain, customer service |
| Podróżowanie i turystyka | accommodation, sightseeing, delay, board, souvenir |
| Kultura | exhibition, festival, review, performance, audience |
| Sport | tournament, coach, training, injury, champion |
| Zdrowie | symptom, prescription, recover, insurance, healthy lifestyle |
| Nauka i technika | device, invention, social media, data, privacy |
| Świat przyrody | environment, pollution, recycling, endangered, climate |
| Państwo i społeczeństwo | government, election, volunteer, equality, charity |

## Jak się uczyć

1. Jeden temat w tygodniu, 15–20 słów i 5 zdań własnych.
2. Kolokacje zamiast pojedynczych słów: make a decision, take a break, do homework.
3. Błędy z dziennika dopisuj do list.
