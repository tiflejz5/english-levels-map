# Liczba mnoga rzeczowników

Większość rzeczowników dostaje w liczbie mnogiej końcówkę **-s**. Do zapamiętania jest kilka reguł pisowni i krótka lista wyjątków.

## Reguły

| Reguła | Przykłady |
| --- | --- |
| zwykle **+s** | *book → books, car → cars* |
| po -s, -ss, -sh, -ch, -x → **+es** | *bus → buses, glass → glasses, dish → dishes, watch → watches, box → boxes* |
| spółgłoska + y → **-ies** | *city → cities, baby → babies* |
| samogłoska + y → **+s** | *day → days, boy → boys* |
| -f / -fe → **-ves** | *knife → knives, wife → wives, half → halves* |
| spółgłoska + o → często **+es** | *tomato → tomatoes, potato → potatoes* (ale *photo → photos, piano → pianos*) |

## Najważniejsze formy nieregularne

| Pojedyncza | Mnoga | Polski |
| --- | --- | --- |
| man | men | mężczyźni |
| woman | women | kobiety |
| child | children | dzieci |
| person | people | ludzie |
| foot | feet | stopy |
| tooth | teeth | zęby |
| mouse | mice | myszy |
| fish | fish | ryby |
| sheep | sheep | owce |

## Rzeczowniki tylko w liczbie mnogiej

*trousers, jeans, glasses (okulary), scissors, clothes* – łączą się z *are*: *My jeans are blue.* Gdy liczymy: *a pair of jeans*.

## Wymowa końcówki

- /s/ po bezdźwięcznych: *books, cats*
- /z/ po dźwięcznych: *dogs, cars*
- /ɪz/ po -s, -sh, -ch, -x: *buses, watches* – dodatkowa sylaba!

## Przykłady

| Angielski | Polski |
| --- | --- |
| I've got two children. | Mam dwoje dzieci. |
| There are three women in my team. | W moim zespole są trzy kobiety. |
| Many people live in big cities. | Wielu ludzi mieszka w dużych miastach. |
| My feet hurt. | Bolą mnie stopy. |
| Where are my glasses? | Gdzie są moje okulary? |

## Typowe błędy Polaków

- ❌ *childrens, peoples* → ✅ *children, people* – to już liczba mnoga.
- ❌ *The people is nice.* → ✅ *The people are nice.*
- ❌ *My trousers is…* → ✅ *My trousers are…*
- ❌ *informations, advices* → ✅ *information, advice* – niepoliczalne, bez -s.
