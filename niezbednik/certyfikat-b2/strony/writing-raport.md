# Raport

Raport pojawia się w zwykłej wersji B2 First. Pisze się go do konkretnej osoby, np. dyrektora lub komitetu.

## Struktura

1. **Tytuł**: Report on...
2. **Introduction:** cel raportu.
3. **Nagłówki sekcji** (np. Facilities, Problems).
4. **Conclusion / Recommendations:** konkretne propozycje.

## Styl

Formalny lub neutralny, zdania zwięzłe, bez zbędnych emocji. Możliwe są nagłówki i wypunktowania.

## Zwroty

The aim of this report is to..., It was found that..., The majority of students..., I would recommend that..., It would be a good idea to...
