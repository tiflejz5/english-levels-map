# Esej (Part 1)

Dostajesz temat i **dwa pomysły** w ramce. Omawiasz oba i dodajesz **własny**.

## Struktura (ok. 170 słów)

1. **Wstęp:** temat, krótko, bez opinii lub z tezą.
2. **Pomysł 1:** argument plus przykład.
3. **Pomysł 2:** argument plus przykład.
4. **Własny pomysł:** jeden akapit lub zdanie (zaznacz, że to dodatkowy punkt).
5. **Zakończenie:** podsumowanie i opinia.

## Zwroty

| Funkcja | Zwroty |
| --- | --- |
| Wstęp | Nowadays..., It is often argued that... |
| Dodawanie | Furthermore, In addition, What is more |
| Kontrast | However, On the other hand, Nevertheless |
| Przyczyna / skutek | As a result, Consequently, This is why |
| Własny pomysł | Another point worth mentioning is... |
| Zakończenie | All things considered, To sum up |

## Błędy do uniknięcia

- Pominięcie jednego pomysłu z ramki.
- Brak własnego pomysłu.
- Slang i skróty w tonie formalnym.
- Brak przykładów.
