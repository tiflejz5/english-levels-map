# Bilety, rezerwacje i proste problemy

W podróży większość rozmów to krótkie transakcje: bilet, stolik, pokój. Kiedy coś pójdzie nie tak, trzeba umieć spokojnie to zgłosić.

## Bilety

| Zwrot | Polski |
| --- | --- |
| A single / return ticket to Oxford, please. (BrE) | Bilet w jedną stronę / powrotny do Oksfordu. |
| One-way / round-trip ticket (AmE) | w jedną stronę / powrotny |
| What time is the next train to…? | O której jest następny pociąg do…? |
| Which platform does it leave from? | Z którego peronu odjeżdża? |
| Do I need to change? | Czy muszę się przesiadać? |
| How long does it take? | Ile trwa podróż? |

## Rezerwacje

| Zwrot | Polski |
| --- | --- |
| I'd like to book a table for two for 8 p.m. | Chciałbym zarezerwować stolik dla dwóch osób na 20:00. |
| I have a reservation in the name of Nowak. | Mam rezerwację na nazwisko Nowak. |
| Do you have a double room for two nights? | Czy macie pokój dwuosobowy na dwie noce? |
| Is breakfast included? | Czy śniadanie jest wliczone? |
| What time is check-out? | O której jest wymeldowanie? |

## Zgłaszanie problemu

| Zwrot | Polski |
| --- | --- |
| Excuse me, there's a problem with my room. | Przepraszam, jest problem z moim pokojem. |
| The air conditioning doesn't work. | Klimatyzacja nie działa. |
| There's no hot water. | Nie ma ciepłej wody. |
| I think there's a mistake in the bill. | Myślę, że w rachunku jest błąd. |
| This isn't what I ordered. | To nie jest to, co zamawiałem. |
| Could you change it, please? | Czy można to wymienić? |
| I've lost my ticket / key. | Zgubiłem bilet / klucz. |

## Przykładowy dialog

> **Guest:** Excuse me, there's a problem with my room. The shower doesn't work.
> **Reception:** Oh, I'm sorry about that. What's your room number?
> **Guest:** 214.
> **Reception:** I'll send someone right away. Or would you like to change rooms?
> **Guest:** Yes, I'd like a different room, please.

## Typowe błędy Polaków

- ❌ *It's not working the shower.* → ✅ *The shower doesn't work / isn't working.*
- ❌ *I want a table.* → ✅ *I'd like to book a table.*
- ❌ *I have a reservation on the name…* → ✅ *in the name of…*
- ❌ *bilet normalny* → nie ma odpowiednika; mów *adult ticket*.

## Ćwiczenie

Przetłumacz.

1. Poproszę bilet powrotny do Londynu.
2. Chciałbym zarezerwować stolik dla czterech osób.
3. Czy śniadanie jest wliczone?
4. Ogrzewanie nie działa.
5. Mam rezerwację na nazwisko Kowalski.
6. Z którego peronu odjeżdża pociąg?
